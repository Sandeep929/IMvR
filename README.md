# JC Bricks Enterprise Management System

A production-grade, offline-first desktop application designed for **JC Bricks Manufacturing** to manage invoices, products, customers, raw materials, and reports. The application utilizes a hybrid database architecture featuring a local SQLite engine for zero-latency offline operations and background synchronization to a cloud-based MongoDB Atlas cluster.

---

## Key Features

- **Billing & Invoice Management**: 
  - Create and manage customer invoices.
  - Export to PDF and print standardized invoices with dynamic tax (GST) calculations.
  - Automatic calculation of cumulative summaries and product-wise breakdowns.
- **Customer Directory & Ledger**:
  - Detailed customer profiles with searchable dropdowns.
  - Real-time customer statements and transaction history.
- **Raw Materials Tracking**:
  - Keep track of factory raw materials including *Randaa*, *Dhula*, *Bakaas*, *Dholpuri Clay*, *Burada*, and *Soyabean Bagda*.
- **Sync & Backup Engine**:
  - Dual-database sync: Auto-synchronizes local SQLite transactions with a cloud MongoDB Atlas database in the background whenever an internet connection is detected.
- **Password Recovery & Verification (OTP)**:
  - Step-based secure forgot password flow.
  - Sends a secure 6-digit One-Time Password (OTP) to the administrator's configured email address.
- **Gmail Configuration Interface**:
  - Set and verify Gmail SMTP settings directly within the desktop application interface.
  - Immediate nodemailer handshake validation to prevent saving invalid credentials.
  - Settings are saved securely on the server-side environment config (`.env`) rather than in the database.

## Tech Stack

### Frontend (Desktop Client)
- **Framework**: React.js (Vite)
- **Runtime**: Electron (desktop shell wrapper)
- **Icons**: Lucide React
- **Styling**: Vanilla CSS with modern layout grids and typography

### Backend (Local API Server)
- **Runtime**: Node.js & Express
- **Local DB**: SQLite3 (using `better-sqlite3` or standard sqlite)
- **Cloud DB**: MongoDB (using Mongoose)
- **Transactional Mailer**: Nodemailer

## Setup & Installation

### Prerequisites
- [Node.js](https://nodejs.org/) (v16 or higher)
- [npm](https://www.npmjs.com/)

### Step 1: Configure Backend Environment
Navigate to the `backend/` directory, create a `.env` file, and populate the following keys:
```env
PORT=5000
MONGODB_URI=your_mongodb_atlas_connection_string
# SMTP keys will be written automatically by the UI when configured, 
# or you can set them manually here:
SMTP_HOST=smtp.gmail.com
SMTP_PORT=587
SMTP_USER=your-email@gmail.com
SMTP_PASS=your-gmail-app-password
```

### Step 2: Install Backend Dependencies & Start Server
```bash
cd backend
npm install
node server.js
```
The local server will start running at `http://localhost:5000` and output synchronization logs to the terminal.

### Step 3: Install UI Dependencies & Start Client
In a new terminal window, navigate to the `UI/` folder and run:
```bash
cd UI
npm install
npm run electron
```
This compiles the React code with Vite and launches the Electron application frame.

## Email (SMTP) Configuration Guide

To enable forgot password recovery:
1. Log into the application and navigate to **Settings** in the sidebar.
2. Select the **Gmail Setup** tab.
3. Enter your **Gmail Address**.
4. Generate a **Google App Password**:
   - Go to your [Google Account Security settings](https://myaccount.google.com/security).
   - Enable **2-Step Verification**.
   - Navigate to **App passwords** (under "How you sign in to Google").
   - Create a new app password (e.g., select *Other* and name it "JC Bricks Management").
   - Copy the 16-character code generated by Google.
5. Paste the 16-character code into the **Gmail App Password** field in the app UI.
6. Click **Save & Verify Config**. The backend will test connection settings. If valid, the settings are instantly applied.
